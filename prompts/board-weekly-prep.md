# A-1　取締役週次定例：次回分の準備

対象会議：`board-weekly`（取締役週次定例）
実行タイミング：毎週金曜 09:00

取締役週次定例の次回分の準備をしてください。

---

## 手順

### 1. 次回開催を確認する

1. Google Calendar の `list_events` で、実行日から7日先までを対象に、タイトルに `calendar_title_keyword`（`取締役mtg`）を含む予定を探す。いちばん近い1件を次回開催とする。

   **カレンダー上の予定名は「取締役mtg」で、会議体の正式名称とは違う。**「取締役週次定例」で検索すると1件もヒットしない。
2. 次回予定が見つからない場合は、**その旨だけ報告して終了する。** Notionには何も書かない。
3. 進行役を確認する。カレンダー予定の説明欄やタイトルに進行役の記載があればそれを使う。**記載がなければ進行は設定せず、Slack投稿の（進行：◯◯）も丸ごと省略する。** 輪番の順番をAIが推測して埋めない。

### 2. 次回分のページを作る

1. まず、次回開催日のページが既にあるか確認する。`notion-search` で議事録DBを検索する。

   ```
   notion-search: query="取締役週次定例 議事録",
                  data_source_url="collection://f3605c0a-be8a-410e-86bb-66fc5253394a"
   ```

   タイトルが `YYYY-MM-DD 取締役週次定例` の形で次回開催日と一致するページが既にあれば、**作成せず手順3へ進む。** 二重作成を避けるための確認。
2. `notion-duplicate-page` で雛形ページ `3be2fd3d-feaf-81c0-a349-d945465a77d1` を複製する。雛形の構成をそのまま使うため、本文を書き起こして新規作成することはしない。

   Notionの「テンプレートとして保存」に登録済みのテンプレートがある場合は、`notion-create-pages` の `template_id` を使ってもよい。`notion-fetch` でDBを取得したときに `<templates>` セクションが出るかどうかで判断する。
3. `update_properties` で以下を設定する。

   | プロパティ | 値 |
   |---|---|
   | `タイトル` | `YYYY-MM-DD 取締役週次定例`（次回開催日） |
   | `開催日` | 次回開催日（`date:開催日:start`。時刻は入れない＝`is_datetime` は 0） |
   | `ステータス` | `事前記入中` |
   | `進行` | 手順1で確認できた場合のみ設定する |

   参加者・欠席・今週のトップ3・上程先・持ち越し・Zoom録画は、この時点では空のままにする。
4. `update_content` で、複製に含まれる雛形固有の記載を削る。

   - 冒頭の引用ブロック「このページを複製して各回の議事録にしてください。…」を削除する
   - 🟩 トグル内の `【記入例】` で始まる行を削除する（山口の下に2件、【共有のみ】側に1件とそのネスト）

   それ以外の本文（ページの流れの表、🟩 / 🟦 / 🤖 / ⏺️ の4トグルとその中身）は雛形のまま残す。

### 3. 前回の持ち帰りを転記する

1. `notion-search` で、次回開催日より前で最も新しい `YYYY-MM-DD 取締役週次定例` のページを探す。`【雛形】` で始まるページは除く。
2. 前回ページの 🤖 トグル内「4. 持ち帰り」の表から、**期限が次回開催日以前のもの**を拾う。期限が未設定のものも拾う（次回の冒頭で日付を入れる運用のため）。
3. 前回ページの 🤖 トグル内「2. 相談・よもやま」の「結論を出さなかったもの」に記載があれば、それも拾う。
4. 拾った内容を、新規ページの **🟩 トグル内「前回の持ち帰り（自動転記）」の表** へ書き込む。列は 担当／内容／期限／状態。状態は空欄にする（前回時点の状態をAIが判断しない）。

   **この表は 🟩 の中にあるが、A-1 が書き込む例外の欄。** 共通ルール §1-1 の3箇所のうちの1つ。🟩 の他の欄（【経営課題の提起】【共有のみ】）には触らない。
5. 前回ページが見つからない、または拾うものが0件の場合は、表を空のまま残す。行を作らない。

### 4. Slackへ投稿する

`slack_channel_id` が空の場合は投稿せず、本文を出力して終了する。

```
＠取締役　次回の週次定例は MM/DD(曜) hh:mm〜 です（進行：◯◯）

■ 話したいことを、下記Notionページの「事前記入」欄へご記入ください
　（開催前日まで／1分で終わります）
　・【経営課題の提起】この場で話したいこと
　　　→ 挙がった内容は、会議中に「執行役員連携事項」と「取締役課題」に
　　　　 仕分けます。前者は次回の経営レイヤー定例で取締役提案として
　　　　 執行役員に共有します
　・【共有のみ】読んでおいてほしいこと
　　　→ 会議では読み上げません
　→ （Notionページのリンク）

■ 前回からの持ち越し
　・中井：（内容／期限）
　・久保：（内容／期限）
```

- 「■ 前回からの持ち越し」は手順3で転記した内容から作る。**持ち越しがない取締役は行ごと省略する。** 全員なければブロックごと省略する。
- 進行役が確認できなかった場合は「（進行：◯◯）」を省略する。「（進行：未定）」とは書かない。

---

## 【厳守】

- **持ち越しがない取締役は行ごと省略する**（空行を並べない）。
- **資料の提出は求めない。** 記入はタイトル・1行で足りると明記する。
- **Slackスレッドに議題を書くよう促さない。** 記入先はNotionに一本化する。
- **【共有のみ】の記入を「任意」と書かない。** 書いてよい枠であることを明示する。
- 同じ日付のページが既にある場合は作成しない。Slack投稿だけ行う。
- 🟩 の【経営課題の提起】【共有のみ】、🟦、🤖、⏺️ には書き込まない。書き込むのは「前回の持ち帰り（自動転記）」の表だけ。
- 投稿は敬体で書く。命令調にしない。

## 報告

最後に、次の内容を標準出力へ報告する。

- 次回開催日時と、確認できた進行役（できなければその旨）
- 作成したNotionページのURL、または既存ページを使った旨
- 転記した持ち越しの件数と、転記元の前回ページ
- Slack投稿の有無（未投稿ならその理由）
